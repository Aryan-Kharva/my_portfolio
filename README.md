# 🌐 Personal Portfolio (React)

A modern, responsive personal portfolio website built with **React** and **React Router**.  
It showcases my projects, skills, and contact information in a clean and user-friendly layout.

## ✨ Features
- 🎨 Minimalist design with a focus on readability and usability
- 🖼️ Hero section introducing me and my work
- 📂 Projects page with detailed breakdowns for each project:
  - Spin City Market
  - Bollywood Threads
  - Potato Properties
  - DribbleData
- 📄 About Me section with background and interests
- 📬 Contact section with smooth navigation
- 🔗 Reusable Navbar and Footer across all pages
- 🌍 Client-side routing with `react-router-dom`
- 🔄 Smooth scroll-to-section functionality

## 🛠️ Tech Stack
- **React** (Frontend framework)
- **React Router v6** (Client-side routing)
- **JavaScript (ES6+)**
- **HTML5 & CSS3**

## 🚀 Getting Started
Follow these steps to run the portfolio locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/your-portfolio.git
   cd your-portfolio
   
2. Install dependencies:

npm install

3. Start the development server:

npm start

4. Open in your browser:

http://localhost:3000
